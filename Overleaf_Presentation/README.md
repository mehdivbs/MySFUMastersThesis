# Human-Centric Data-Driven Decision Support Presentation

This project contains a 20-slide Beamer presentation based on the thesis.

## Upload to Overleaf

1. Create a new Overleaf project.
2. Upload all files from this folder, including `presentation.tex`.
3. Compile the project with LaTeX.

The presentation expects the thesis figures in the `Figures` folder at the project root.
